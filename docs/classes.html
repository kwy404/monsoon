Reading a variant class

A variant is a prefix and a colon in front of a base class. The base class writes the CSS, the prefix decides when it applies.

State and scheme variants

hover: focus: focus-within: focus-visible: active: disabled: group-hover: peer-checked: first: last: odd: even: motion-safe: motion-reduce: dark:

Breakpoints

sm: md: lg: xl: 2xl:

Mobile first min-width queries at 640, 768, 1024, 1280 and 1536 pixels.

Container queries

@xs: @sm: @md: @lg: @xl:

Need a parent with the @container class. 20rem to 36rem.

Monsoon

Utility-first CSS with no build step. One stylesheet from a CDN, a whole theme from one seed color, dark mode included.

Interactive parts built with Voodoo.js.

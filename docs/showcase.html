Showcase

Whole pages, built only with Monsoon

3 working apps and 7 complete templates: a product landing, a dashboard, an article, pricing, a product page, a portfolio and auth screens. Each one is plain HTML styled with the Monsoon stylesheet. Open them, resize the window, switch the theme, then read the source.

App

Harbor, a community chat

Sign in, then hop between servers and channels, send messages with code blocks and mentions, react, reply, edit and delete, toggle the member list and re-theme the whole app from one accent color.

appno build

Open app
App

Stack, a kanban board

Drag cards between lists, open a card to edit labels, checklist, due date, members and comments, filter and search the board, add and rename lists, and pick a board color that themes everything.

appno build

Tidal, a calendar

Day, week, month and agenda views with a mini month, color coded calendars, overlapping events laid out side by side, a live current time line, drag to move and a full event editor.

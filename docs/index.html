Why Monsoon

Everything a utility stylesheet needs, nothing to set up

A complete set of utilities and a theme engine written in CSS itself, so the file you link is the whole product.

No build step

Link one stylesheet. No compiler, no config file, no watcher and no JavaScript in your page.

Straight from a CDN

Served by jsDelivr and unpkg from npm. Pin a version for production or host the file yourself.

A theme from one color

Set --seed and every semantic color follows, computed in the browser with OKLCH relative colors.

Dark mode built in

Follows the operating system, and .dark, .light or data-theme switch a page or a single section.

Contrast you can trust

Foregrounds flip to keep 4.5:1 against their fill. Focus ring, skip link and touch target helpers included.

4,616 utilities

Layout, flexbox, grid, spacing, sizing, typography, color, borders, effects, filters, transforms and motion.

7,565 variant classes

hover, focus, active, disabled, group, peer, structural, dark, motion and five breakpoints, where they make sense.

Container queries

Mark a parent with @container and style children with @xs: to @xl:, independent of the viewport.

About 43 kB brotli

The complete minified stylesheet. One request, cached after the first page view.

Optional purge CLI

npx monsooncss purge keeps only the classes your files use. A typical page ends up at a few kilobytes.

Any stack

Plain HTML, PHP, WordPress, Django, Rails, static site generators or any JavaScript framework.

Names that read like CSS

px-4, gap-6, text-muted-foreground: each class says what it writes, so markup stays readable.

How seed theming works

One custom property, a full palette, in pure CSS

No preprocessor computes your colors ahead of time. The browser derives every token from --seed with OKLCH relative color syntax, so changing it at runtime, per page or per section just works.

  1. 1

    Read the seed in OKLCH

    oklch(from var(--seed) l c h) splits any CSS color into perceptual lightness, chroma and hue.

  2. 2

    Keep lightness out of the unsafe band

    Between L 0.52 and 0.66 neither white nor dark text reaches 4.5:1 for every hue, so primary snaps to one side of it.

  3. 3

    Flip the foreground

    A clamp() with a large multiplier acts as a branch free if, choosing white or near black text.

  4. 4

    Switch modes with a number

    --mode is 0 in light and 1 in dark, so the same declarations serve both schemes.

Dark mode, variants and container queries

State, scheme and size in the class name

Variants are generated where they are useful: hover and focus for colors and effects, breakpoints for layout, dark for palette colors. That is what keeps the full file small enough to link directly.

Dark mode with one line

Automatic from the operating system. Force it on a page or a section with one attribute.

State and breakpoints

Prefix a class with a state or a breakpoint. Breakpoints are mobile first.

Container queries

Respond to the width of a parent instead of the viewport.

State variants

hover: focus: focus-within: focus-visible: active: disabled: group-hover: peer-checked: first: last: odd: even: motion-safe: motion-reduce: dark:

Breakpoints (min-width)

Container breakpoints

@xs: 20rem, @sm: 24rem, @md: 28rem, @lg: 32rem, @xl: 36rem

Purge CLI

Ship only the classes you use

The full file is fine for most sites. When every kilobyte counts, one command scans your templates and writes a stylesheet with only the rules they reference, plus the reset, theme tokens and keyframes.

Real output for the repository's kitchen sink demo page.

  • -o, --out
    Output file. Without it the CSS goes to stdout.
  • --safelist a,b
    Classes to keep even if no file mentions them.
  • --no-minify
    Readable output instead of minified CSS.
  • --css file
    Purge another copy of the stylesheet.

FAQ

Questions people ask about Monsoon

Add one tag, <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/monsooncss">, and write classes such as px-4, md:grid-cols-3 or hover:bg-primary in your HTML. Every class is already in the file, so there is no compiler, no config file and no watcher to run.

Yes. The minified file is about 43 kB with brotli and 80 kB with gzip, it is cached by the browser after the first visit, and you can pin an exact version such as monsooncss@0.1.0. If you want the smallest possible file, run npx monsooncss purge once and serve the result yourself.

Set --seed to any CSS color, for example :root { --seed: #0d9488; }. Monsoon derives primary, secondary, accent, surfaces, muted text, borders and the focus ring from it with OKLCH relative colors, in pure CSS. Put style="--seed: teal" on any element to theme only that section.

It is automatic. Monsoon follows prefers-color-scheme, and you can force a scheme with class="dark", class="light" or data-theme="dark" on the root element or on any section. Semantic colors such as bg-surface and text-foreground switch on their own, so most pages need no dark: classes at all.

The seed formulas push the primary color out of the lightness band where neither white nor dark text is safe, and flip the foreground to match. The test suite checks 4.5:1 (WCAG AA) for every token pair across 18 named seeds and a sweep of 2,197 sRGB seeds, in light and dark mode.

Yes. Add @container to a parent and use @xs: to @xl: on its children, for example @md:flex-row. The container breakpoints run from 20rem to 36rem and are generated for layout, spacing, sizing and text utilities.

Yes. It is a plain stylesheet, so it works in any template language. Link it from your layout, write classes in your templates, and if you want a smaller file point the purge command at your template folders, for example "templates/**/*.html" or "app/views/**/*.erb".

Stacked variants such as dark:hover:, arbitrary values such as w-[37px] and the important modifier are not part of a prebuilt stylesheet. Opacity modifiers like bg-primary/90 exist for semantic colors, black and white. For anything else, a style attribute or a few lines of your own CSS next to Monsoon work fine.

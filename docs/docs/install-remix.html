Installation

Install Monsoon in Remix

Remix manages stylesheets through the links export, which renders <link> tags into <Links /> in the root. Import Monsoon with ?url, return it from links, and the stylesheet is in place before hydration.

2 min readRemix

#Install

These examples use Remix with Vite. React Router v7 in framework mode is the successor of Remix and uses the same approach; only the imports change (see the note below).

?url asks Vite for the URL of the built file instead of injecting it, which is what links expects. The vite/client types already declare *?url imports, so TypeScript is satisfied. A plain import 'monsooncss' in root.tsx also works if you prefer side effect imports.

React Router v7: import Links, Meta, Outlet, Scripts and ScrollRestoration from 'react-router', and type the export as Route.LinksFunction with import type { Route } from './+types/root'. Everything else on this page is unchanged.

suppressHydrationWarning on <html> is needed because the head script adds dark or light there before React hydrates.

#Using the purge CLI

Alias the package for builds only. The pattern form is needed here, because a plain string alias would not match the ?url suffix:

In React Router v7 the scripts are react-router dev and react-router build, and the plugin is reactRouter() from @react-router/dev/vite. With the CDN setup, write to public/monsoon.css and return /monsoon.css from links.

The purge CLI reads your files as plain text and keeps every class name it can see. It cannot see a name that is assembled at runtime, so write each class in full: isActive ? 'bg-primary' : 'bg-muted' survives a purge, 'bg-' + color does not. Names that only exist at runtime (from a database, a CMS or an API) go in --safelist bg-success,bg-danger.

The purged file always keeps the reset, the theme tokens, the .dark and .light scopes and the keyframes, so dark mode and --seed keep working. See the purge CLI reference for every option.

#Frequently asked questions

Should I use the links export or a side effect import?

Both work with Vite. links with ?url is the documented Remix pattern and lets you add media or preload hints; the side effect import is shorter.

Does this work in React Router v7 framework mode?

Yes. Swap the imports to react-router, type the export with Route.LinksFunction, and keep the rest of the setup.

Select (custom)

A fully custom select over a native one, which stays in the form with its value and change events in sync. Options can carry an icon, an image, a color or a description, optgroups become headings, long lists get a search box, multiple shows chips, and it can be clearable. Keyboard and screen readers follow the WAI-ARIA select only combobox pattern, and the size, tone and variant classes of .select carry over. Needs monsoon.js.

Interactive22 classesNeeds monsoon.jsLight and dark

Needs monsoon.js. The styles work on their own, and the behavior comes from the optional interactive layer: add <script src="https://cdn.jsdelivr.net/npm/monsooncss/dist/monsoon.js" defer></script> or import 'monsooncss/js'. See the interactive layer.

#JavaScript API

Attribute

Options

OptionDescription
data-m-select-search (on by default from 10 options, "false" turns it off)
data-m-select-clearable
data-m-select-placeholder="Pick one" (or an empty first option)
multiple on the select
data-description, data-icon, data-image or data-color on an option
select-xs to select-xl, select-primary, select-ghost and select-filled

Methods

MethodDescription
Monsoon.select(el).open()
Monsoon.select(el).close()
Monsoon.select(el).value
Monsoon.select(el).value = "team"
Monsoon.select(el).refresh() after changing select.value in code

Events

EventDescription
change and input on the native select
monsoon:change { value }

#Usage

The styles ship inside the same stylesheet as the utilities, and the behavior comes from the optional monsoon.js script, which enhances any element with a matching data-m attribute, including markup added later.

Theme it with --seed on any ancestor, for example style="--seed: #0d9488", and force a scheme with class="dark" or class="light" on a wrapper.

#Accessibility

  • Give every control a visible label linked with for, or an aria-label when the purpose is obvious from context. Link help and error text with aria-describedby; invalid styles use :user-invalid, so they appear only after the user interacts.
  • Every interactive part shows a visible focus ring with :focus-visible, and tone colors pair with -foreground tokens that keep text at 4.5:1 or better in light and dark mode.

# Security Policy

## Supported versions

Security fixes are released for the latest minor version of `monsooncss`.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report it privately through GitHub security advisories:
https://github.com/kwy404/monsoon/security/advisories/new

Include what you found, how to reproduce it and the impact you expect. You should get a first reply within a few days. Once a fix is ready it will be released and the advisory published with credit, unless you prefer to stay anonymous.

## Scope

Monsoon ships a static stylesheet and a small command line tool (`monsooncss`) that reads files you point it at and writes a CSS file. Reports about the CLI (for example path handling) and about the published package contents are in scope.
